BlockBridge

Join any Bedrock server from your console.

Free Android app. Your phone shows the server as a LAN game, so Xbox, PlayStation and Switch can join it from the Friends tab.

ServerAny Bedrock server on the internet

Set up

  1. Download the APK on your Android phone and open it. If Android asks, allow your browser to install unknown apps.
  2. Open BlockBridge and add a server: address and port (port is usually 19132).
  3. Tap the server. A notification shows it's being shared. Keep the phone on the same Wi‑Fi as your console.
  4. On your console open Minecraft → Play → Friends. The server shows up under LAN Games. Join it.

Questions

The server doesn't show up under LAN Games

Phone and console must be on the same Wi‑Fi network (not a guest network). Some routers block devices from seeing each other ("AP isolation"); turn that off. Check the log at the bottom of the app.

Does my phone have to stay on?

Yes. All game data goes through the phone while you play. The screen can be off; the app keeps running in the background.
